# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-01-18

### Added
- Initial project setup
- AI content generation with Claude Sonnet 4.5
- Multi-platform content generation (Instagram, Facebook, Twitter, LinkedIn, TikTok)
- Image generation with Stable Diffusion XL
- Email campaign generation
- Ad copy generation with A/B testing variants
- Video script generation
- Carousel image creation
- Smart scheduling system with optimal timing
- Multi-platform social media publisher
- PostgreSQL database with SQLAlchemy ORM
- Analytics dashboard with performance metrics
- REST API with FastAPI
- Next.js 14 frontend with TailwindCSS
- Docker containerization
- Celery task queue for async operations
- Redis caching and message broker
- Subscription tier system (Free, Starter, Pro, Agency)

### Features
- Platform-specific content optimization
- Historical data-based scheduling
- Campaign management
- Performance analytics
- AI-powered insights
- Content optimization
- Multi-account support

### Tech Stack
- Backend: Python 3.11, FastAPI, SQLAlchemy, Celery
- Frontend: Next.js 14, React 18, TailwindCSS
- AI: Anthropic Claude API, Replicate (SDXL)
- Database: PostgreSQL
- Cache/Queue: Redis
- Deployment: Docker, Docker Compose
